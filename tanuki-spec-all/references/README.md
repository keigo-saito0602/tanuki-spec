# references — 参照仕様と出典の扱い

本ファイルは主に`tanuki-spec-generator`が生成時に使う参照仕様の扱いを説明する。

## 1. 生成時に参照する「過去仕様」（都度指定）

本SKILLは参照元を固定しない。生成のたびに、参照したい過去案件の
仕様書リポジトリ/ファイルの**パスを引数として渡す**。

- 例（soil-groove を参照する場合）:
  `/Users/saitoukeigo/Documents/Programming/soil-groove` の `codex-task-*` 指示書やワイヤーフレーム別紙
- 無指定なら参照なしで、ユーザーストーリーのみから生成する。

参照仕様を使って埋めた項目は、必ず**出典（リポジトリ/ファイル名）を項目脚注に明記**すること
（`SKILL.md` の②穴埋め生成ルール）。

## 2. 品質項目の出典（項目マスターの根拠）

`spec-items.yaml` の各項目 `source` フィールドが出典を保持している。元資料の版・保管場所・SHA-256・位置指定の書式は [`research/source-register.yaml`](../research/source-register.yaml) を正本とする。原本を差し替えたらハッシュを更新し、該当項目の位置指定を再確認する。

| 略称 | 元ファイル | 種別 |
| --- | --- | --- |
| 要件定義pptx | CA5210_業務システム要件定義_講師用v5.23.pptx | 要件定義の要点 |
| 設計pptx | CA5010_業務システム設計の要点v5.22.pptx | 基本/詳細設計の要点 |
| 品質項目要件定義 | OPEN_品質項目（要件定義）v1.21.xlsx | 要件定義の品質チェックリスト |
| 品質項目設計 | OPEN_品質項目（設計：外部仕様）v1.21.xlsx | 外部設計の品質チェックリスト |
| 非機能一覧 | 非機能要件・対応方針一覧_.xlsx | IPA非機能要求グレード |
| AI品質GL | 生成AI活用開発における品質管理ガイドライン_v1.2.pdf | 生成AI開発の品質管理 |

> 元資料は第三者の著作物（研修教材・ガイドライン）のため、本文はリポジトリに同梱しない。
> `spec-items.yaml` は各項目の「見出し・目的・出典の対応表」であり、原文の複製ではない。
> 原本はユーザのVaultルートに保管。

## 3. Web調査の扱い

外部情報を品質基準へ採用する場合は、URL・取得日・採用理由・適用範囲を `research/` 配下へ記録する。一次情報（公式ドキュメント・原著論文）を優先し、本文の複製は保存しない。

## 4. ナレッジ蓄積（運用で育てる）

`evaluation/ai-quality-rubric.md §2⑤` に従い、生成の良否・気づきをこのフォルダに追記していく
（例: `learnings.md`）。溜まった知見は `spec-items.yaml` の項目追加/修正へ反映する。
