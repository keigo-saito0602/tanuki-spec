# 認知科学に基づく資料構成の原則（正本）

このリポジトリの仕様書テンプレート（`spec-items.yaml`の`review_checklist`/`audience`/凡例、レンダラの体裁）と、
将来の汎用スキル `tanuki-doc-architect` は、すべてこの原則を実装したものである。原則を1箇所に集約し二重管理を防ぐ。

## 読み手モデル（最重要）

- 要件定義書・プロダクトバックログ = 非技術者（クライアント・経営視点）。結論ファースト・平易・段階的開示。
- 基本設計書・詳細設計書 = 第三者の技術者。多視点レビュー（PBR）・トレース・ADR。

## 11原則

1. 認知負荷理論（Sweller）: 無駄な負荷（機械マーカー・著者メタ・重複・装飾）を本文から隔離する。
2. 段階的開示（Nielsen）: サマリ層→本論層→付録層の3層。
3. 結論ファースト（Minto/BLUF）: 文書・各節を結論文で始める。
4. スキャン読み（NN/g F-pattern/layer-cake）: 見出しと行頭に情報を凝縮する。
5. 合図・強調（Mayer Signaling/Von Restorff/Gestalt）: 強調は意味に固定し凡例で宣言する。
6. チャンク化（Miller 7±2）: 1リスト5〜7項目、見出しは3階層まで。
7. チェックリスト（Gawande）: 見落としがちな観点を節単位のチェックリストにする。
8. Perspective-Based Reading（Basili/NASA）: 役割視点別に読み多視点で網羅する。
9. トレーサビリティ（RTM）: 要件↔設計↔テストの対応で抜け・影響を可視化する。
10. ADR（Nygard）: 決定・代替案・トレードオフを1判断1レコードで記録する。
11. Plain Language: 短文・能動態・具体語、用語は用語集へ集約する。

## 出典

各原則の一次情報（URL・取得日）は [`../research/web-sources.md`](../research/web-sources.md) の「認知科学に基づく資料構成」節を参照する。番号は上の11原則と対応している。テンプレート改訂で原則の解釈を変える場合は、同節の出典に当たって根拠を確認すること。
