# サンプル入力: ユーザーストーリー

> 本SKILLのE2E動作確認用のサンプル入力。

- **対象工程**: requirements（要件定義）
- **参照仕様**: なし（ユーザーストーリーのみから生成）
- **モード**: full

## ストーリー本文（ざっくり）

「DJ教室の生徒が、空いているレッスン枠をスマホから予約できるようにしたい。
いまはInstagramのDMで予約を受けていて、講師が手動で台帳に書いていて予約漏れや二重予約が起きる。
生徒が自分で空き枠を見て予約・キャンセルできて、確定したら通知が来るようにしたい。」

## ①入力ゲート（INVEST）判定

| 軸 | 判定 | 補足 |
| --- | --- | --- |
| Independent | YES | 予約機能単体で成立 |
| Negotiable | YES | 実装詳細は未固定（What中心） |
| Valuable | YES | 予約漏れ/二重予約の解消という明確な価値 |
| Estimable | YES | 画面数・データ構造を見積もれる |
| Small | YES | 予約/キャンセル/一覧に絞れる |
| Testable | YES | 「空き枠を予約し確定通知が届く」等で合否を書ける |

→ 6軸クリア。生成に進む。
