# tanuki-spec-generator フロー

生成側は起動から③の出力ゲートまでを担当する。全体の役割分担は[ルートFLOW](../FLOW.md)を参照する。

| ステージ | KEIGO | 生成側 |
| --- | --- | --- |
| 0 | 工程・ストーリー・参照仕様を入力 | 起動テンプレートを提示 |
| ① | 不足情報を補足 | INVESTを確認し質問を残す |
| ② | 過去仕様の採用可否を承認 | 根拠付きでドラフトを記入 |
| ③ | 結果を確認 | coverageとspec_gateを実行 |
| 引き渡し | レビューを依頼 | `tanuki-spec-reviewer`へ対象仕様書を渡す |
